BistroCardapio - Sistema Real

Sistema de restaurante / lanchonete em um único arquivo HTML, com React.
Telas

    #/admin - Configura restaurante, cardápio, mesas, QR Code
    #/cliente - Cardápio para o cliente, mesa ou entrega
    #/caixa - Frente de Caixa, PDV com Pix, Dinheiro, Crédito, Débito e troco
    #/cozinha - Pedidos pendentes para a cozinha
    #/entrega - Entregas prontas, finaliza com código de 4 dígitos
    #/estoque - Controle de estoque, baixa automática a cada venda

Como publicar

    Suba este index.html para um repositório no GitHub
    Publique com GitHub Pages, Vercel ou Netlify
    Abra a URL publicada com #/admin, cadastre restaurante e cardápio
    Copie os links de Cliente, Caixa, Cozinha, Entrega e Estoque dentro do Admin

Aviso importante

Os dados ficam salvos no navegador (localStorage). A nuvem só hospeda o arquivo.
Para sincronizar entre celulares diferentes, é preciso um banco na nuvem (Firebase / Supabase).
Para usar em 1 aparelho com várias abas, já funciona.
